# Portfolio

Personal portfolio site for Yadeesh Kumbalathil Ramesh, built with Next.js and Tailwind CSS.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Content

Page content (experience, projects, skills, etc.) lives in [`src/lib/data.ts`](src/lib/data.ts) — edit that file to update the site.

## Deployment

Deployed on [Vercel](https://vercel.com).
